# dfbustosus/homebrew-tap

Homebrew tap for [llmrace](https://github.com/dfbustosus/llmrace) — race LLM
providers head-to-head in your terminal.

## Install

```bash
brew install dfbustosus/tap/llmrace
```

Or add the tap first:

```bash
brew tap dfbustosus/tap
brew install llmrace
```

## What's here

| Formula | Description |
|---|---|
| [`llmrace`](Formula/llmrace.rb) | LLM provider benchmark CLI (macOS ARM/Intel, Linux x86_64) |

## Updates

Formulas are updated automatically with each
[llmrace release](https://github.com/dfbustosus/llmrace/releases).
